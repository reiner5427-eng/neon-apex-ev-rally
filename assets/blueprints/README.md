## Codex / Blender 모델링 사용 지침

### 이미지 확인 시 보정할 부분

- Model S 도면에는 이전 연식의 전면 범퍼·램프 디테일이 일부 섞여 있습니다. 선택한 리프레시 일반형의 실차 사진을 기준으로 전면부를 보정합니다.
- Model Y 도면의 측면·후면 램프 연결 형상은 단순화되어 있습니다. 주니퍼 실차 램프 사진과 대조합니다.
- EV3 이미지에는 루프랙이 그려져 있으나, 표의 1560 mm는 루프랙 제외 높이입니다. 기본형 기준 모델에서는 루프랙을 생략합니다. 도면 속 추가 손잡이처럼 보이는 작은 사각형을 실제 도어 손잡이로 단정하지 않습니다.
- EV6의 램프와 휠 디테일은 개략적인 외형 참고입니다. 최종 모델의 페이스리프트 램프와 트림별 휠은 실차 사진으로 확인합니다.

1. 미터 단위를 사용합니다. 위 치수에 0.001을 곱해 실제 크기로 모델링합니다.
2. 측면에서 전장·전고·축거를 먼저 맞추고, 정면과 평면에서 차체 폭을 맞춥니다. 그림 간 비례가 어긋나면 공식 치수를 기준으로 개별 참조 평면을 조정합니다.
3. 차량 앞쪽을 -Y, 오른쪽을 +X, 위쪽을 +Z로 둡니다. 원점은 앞뒤 차축의 중간 지점 바로 아래 지면에 둡니다. 이는 이 프로젝트용 권장 좌표 규칙입니다.
4. 좌우 대칭 차체를 만들고 차체, 유리, 네 바퀴, 헤드램프, 테일램프를 별도 오브젝트로 나눕니다. 바퀴 원점은 각 휠 중심에 둡니다.
5. 실루엣과 휠 위치를 먼저 확인한 다음 패널선·손잡이·미러·램프를 추가합니다. 도면의 선은 메시 토폴로지가 아닌 외관 경계입니다.
6. 생성 이미지의 숫자가 아래 공식 자료 또는 위 표와 다르면 공식 자료와 표를 우선합니다. 미제공 치수는 임의의 실측값처럼 사용하지 않습니다.
